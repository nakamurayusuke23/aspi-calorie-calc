# カロリー＆PFC計算機

ニュートリションコーチ準拠のカロリー＆PFC即時算出ツール（静的Webアプリ）。

## 起動

`index.html` を Safari/Chrome で開くだけ。サーバ・ビルド不要。

## 計算根拠

- ハリス・ベネディクト式（BMR）
- 身体活動係数 ×1.2 〜 ×1.9（5段階）
- 目的別目標カロリー（減量 -500 / 維持 / 増量 +500）
- PFC配分: P=体重×2.0g、C=総カロリー×50%、F=残り
- 出典: 『ニュートリションコーチ』(2025, 株式会社ASPIREST) p.74〜p.78

## 機能

- 性別・年齢・身長・体重・活動量・目的の入力
- 目標逆算モード（目標kg+期間→1日カロリー赤字/黒字を逆算）
- 8条件の自動アラート（極端カロリー / 急速減量 / PFC偏り等）
- プレゼンモード切替（営業/見学者向けヒーロー数値表示）
- localStorage で入力値・モード状態を保存
- レスポンシブ（iPad縦/横/PC/スマホ）

## ファイル構成
